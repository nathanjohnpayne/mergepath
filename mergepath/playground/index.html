Replay your real PRs

    

      
Public repo? Load it right here. The page fetches the repo's recent merged PRs straight from the GitHub REST API—unauthenticated, read-only, nothing stored.

      

        
        
        
        
        
      

      
Unauthenticated GitHub allows 60 requests/hr per IP; one load costs 1 + one request per PR. PRs with more than 100 changed files are counted from their first 100 files only.

      
Private repo, or a bigger pull? The browser can't shell out to gh—a tiny helper script does it for you: it lists your repo's recent merged PRs with your authenticated gh, bakes the data into a copy of this file, and opens the copy in a new tab.

      
    
        
  1. Open a terminal at your repo root (the folder with .github/review-policy.yml).
    2. 
        
  2. Run the helper. Default pulls the last 20 merged PRs:
          
    $./scripts/policy-sim.sh
    
          Or pass a custom limit (any positive integer):
          
    $./scripts/policy-sim.sh 50
    
        
    3. 
        
  3. A new browser tab opens with the same dashboard, but the live badge will be lit and the routing simulation will replay your real merged PRs under the current policy.
    4. 
      

    

    

      Needs gh, jq, and python3 on PATH. gh must be authenticated (gh auth status). Nothing is written back to your repo—the baked copy lives in a temp file.

# Pinned yq bootstrap

`scripts/lib/ensure-yq.sh` supplies the CI parser when mikefarah/yq is absent. An already-present mikefarah/yq retains the existing no-op behavior. With `--ci-only`, a local run also skips installation unless `GITHUB_ACTIONS=true`.

The default release is v4.53.6. On Linux, `uname -m` selects `yq_linux_amd64` for `x86_64` and `yq_linux_arm64` for `aarch64` or `arm64`; other architectures fail before download or privileged operations. The script pins the official per-asset SHA-256 values from the [v4.53.6 release metadata](https://github.com/mikefarah/yq/releases/tag/v4.53.6). Download to an unprivileged temporary directory and verify the complete binary with SHA-256 before any privileged operation. Stage the verified executable with `sudo install` inside a private root-owned directory beside the destination, then atomically replace exactly the destination with GNU `mv -fT` before running its version check. This fallback targets Linux CI, as do its downloaded binaries. A failed download, invalid expected digest or checksum mismatch must fail before installation or execution. A staging or rename failure also preserves any existing destination and must not execute the downloaded binary. A destination directory is refused rather than receiving a nested executable. Temporary downloads and staging directories are removed on exit.

`ENSURE_YQ_DEST` redirects the install destination for offline tests. `ENSURE_YQ_SHA256` supplies the expected digest for the selected architecture's asset; overriding `ENSURE_YQ_VERSION` requires an explicit digest. Neither override permits an unchecked download.

The weekly drift audit uses the same release version and retains its existing checksum verification. Cloud setup validates the requested stable version against its minimum before returning a successful dry run, then checks the verified temporary binary with the same minimum predicate before copying it into the install prefix. An under-minimum or non-semver version must fail without downloading, and a verified but unsuitable binary must leave any existing prefix binary untouched. Tests of older versions must continue to exercise rejection of releases below v4.53.6.

`tests/test_resolve_pr_threads_verified_propagation.sh` exercises present-parser and local no-ops, missing and wrong-implementation installs, verified fixture installation, checksum mismatch, invalid digest, missing override digest and download failure. It also covers partial staging failure, rename failure, atomic success and a destination directory, with offline privilege and download shims. The installed v4.53.6 parser must pass `check_sync_manifest`, `check_resolve_pr_threads` and `check_doc_ownership`.
